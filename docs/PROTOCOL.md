# Протокол последовательного порта (прошивка 2.0)

USB-порт Arduino Nano, **115200 бод, 8N1**. Обмен текстовый: адаптер пишет строки, оканчивающиеся `CR LF`,
и принимает односимвольные команды (перевод строки после команды не нужен, `CR`/`LF` игнорируются).

Тип строки определяется первым словом. Незнакомые строки приёмник должен пропускать.

## Строки адаптера

| Строка | Когда | Смысл |
|---|---|---|
| `ADAPTER PSA-CAN <версия> <FULL\|LITE>` | при старте и в ответ на `?` | адаптер (пере)запустился; следом идут все строки `MODE` и `STATE` с текущими значениями |
| `CAN <ID>\t<DLC>\t<B0>\t<B1>…` | см. «Пересылка пакетов» | пакет шины; все числа в HEX без ведущих нулей, разделитель — табуляция |
| `<ID>\t<DLC>\t<B0>…` (без `CAN `) | только при включённом логе (`L` или `F`) | каждый пакет шины подряд |
| `KEY <имя>` | при отпускании кнопки, которую держали меньше 0,5 с (кнопки меню — меньше 1 с); колёсико — на каждый пакет с изменившимся счётчиком | короткое нажатие |
| `KEY <имя> LONG` | при отпускании кнопки, которую держали дольше | долгое нажатие |
| `STATE REVERSE ON\|OFF` | при изменении | сигнал «задний ход» для магнитолы (с учётом режимов прицепа и ручного включения) |
| `STATE ILLUMINATION ON\|OFF` | при изменении | сигнал «подсветка» (бит `ILLUMINATION_MASK` пакета 0x128) |
| `MODE TRAILER ON\|OFF` | при изменении | режим прицепа: задняя передача не включает `STATE REVERSE` |
| `MODE REVERSE ON\|OFF` | при изменении | камера включена вручную |
| `MODE KEYWIRE ON\|OFF` | при изменении | адаптер нажимает резистивные кнопки на проводе KEY (в варианте LITE всегда `OFF`) |
| `# <текст>` | при уровне отладки 1–2 | пояснения для человека, разбирать не нужно |

### Имена кнопок

| Имя | Источник | Долгое | Резистивная кнопка (FULL) |
|---|---|---|---|
| `VOL_DOWN`, `VOL_UP`, `MUTE` | 0x21F, байт 0: `0x04`, `0x08`, оба сразу | да | да |
| `SEEK_FWD` | 0x21F, байт 0: `0x80` | да | да |
| `SEEK_BACK`, `SOURCE` | 0x21F, байт 0: `0x40`, `0x02` — по описаниям шины, на автомобиле не проверено | да | да (новые сопротивления) |
| `SCROLL_UP`, `SCROLL_DOWN` | 0x21F, байт 1 — счётчик колёсика | нет | да |
| `MODE`, `MENU`, `ESC`, `OK` | 0x0A2, байт 1: `0x04`, `0x08`, `0x10`, `0x20` | да (1 с) | нет |

Долгое `OK` переключает режим прицепа, долгое `ESC` — ручное включение камеры (строка `KEY … LONG` при этом тоже приходит).

### Пересылка пакетов

Пакет из списка `FORWARDED_FRAMES` (`Config.h`) отправляется, когда его содержимое изменилось, но не чаще
своего интервала; без изменений — раз в 2 с, пока он продолжает приходить с шины. Если шина замолчала, повторов нет.

| ID | Мин. интервал | Содержимое |
|---|---|---|
| `1A1` | сразу | сообщения бортового компьютера |
| `220` | сразу | двери |
| `128` | сразу | лампы, указатели поворота |
| `F6` | 500 мс | зажигание, температура ОЖ, одометр, задний ход |
| `B6` | 250 мс | обороты, скорость |
| `221` | 500 мс | БК: мгновенный расход, запас хода |
| `161` | 1 с | уровень топлива, температура масла |
| `261`, `2A1` | 1 с | БК: поездка 1 и 2 |

Строка пакета пишется в порт только если целиком помещается в буфер передачи, поэтому вывод не задерживает приём шины.

## Команды адаптеру

| Команда | Действие |
|---|---|
| `?` | повторить строку `ADAPTER` и все `MODE` / `STATE` |
| `1`–`9` | кнопка панели штатной магнитолы для бортового компьютера (пакет 0x3E5): 1 MODE, 2 вниз, 3 DARK, 4 влево, 5 OK, 6 вправо, 7 ESC, 8 вверх, 9 MENU |
| `R` / `r` | включить / выключить камеру вручную (`MODE REVERSE`) |
| `K` / `k` | включить / выключить нажатие резистивных кнопок (`MODE KEYWIRE`). После перезапуска адаптера снова включено — приложение, которое само обрабатывает `KEY`, шлёт `k` на каждую строку `ADAPTER` |
| `L` / `l` | включить / выключить вывод всей шины |
| `S`, `D`, `F` | уровень отладки: 0 — тихо, 1 — строки `#`, 2 — ещё и вся шина |
| `s` / `f` | начать / закончить режим обучения магнитолы: шина не обрабатывается, работают команды ниже |
| `I` / `i` | (в режиме обучения) включить / выключить подсветку |
| `v` `V` `m` `n` `b` `o` `t` `T` | (в режиме обучения, FULL) нажать на 1,5 с резистивную кнопку: громкость −, громкость +, без звука, вперёд, назад, источник, колёсико −, колёсико + |
| `q` `Q` `w` `W` `B` `O` | то же для долгих нажатий: громкость −, громкость +, без звука, вперёд, назад, источник |
